# Open Wander Homebrew Tap

Homebrew formulae for [Open Wander](https://github.com/open-wander) tools.

## Installation

```bash
brew tap open-wander/tap
brew install ramble
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `ramble` | CLI for deploying Nomad packs and jobs |

## Updating

```bash
brew update
brew upgrade ramble
```
